O que é Acessibilidade Web?

Acessibilidade web significa garantir que pessoas com deficiências visuais, motoras, auditivas ou cognitivas consigam usar o site da mesma forma que qualquer outro usuário. Isso inclui pessoas que usam leitores de tela (como NVDA ou JAWS), navegação por teclado, teclados virtuais em celulares ou que precisam de texto alternativo para imagens. As diretrizes internacionais são definidas pelo WCAG 2.1 (Web Content Accessibility Guidelines).

Impacto real: No Brasil, cerca de 18,6 milhões de pessoas têm alguma deficiência visual (IBGE 2019). Acessibilidade também melhora o SEO e a experiência de todos os usuários.

1. Atributo de Idioma lang

lang="pt-BR" Presente nas 3 páginas
O atributo lang na tag <html> informa ao leitor de tela em qual idioma a página está escrita. Com isso, o software usa o motor de síntese de voz correto — pronunciando palavras em português brasileiro corretamente, incluindo acentos e entonação. Sem esse atributo, o leitor de tela pode tentar ler o conteúdo em inglês.
Localização: linha 2 de cada página HTML
<html lang="pt-BR">

2. Meta Tags de Cabeçalho

meta charset="UTF-8" Presente nas 3 páginas
Define a codificação de caracteres da página. O UTF-8 garante que todos os caracteres especiais do português — ã, ç, é, ú, ô — sejam exibidos corretamente tanto no navegador quanto nos leitores de tela. Sem isso, esses caracteres apareceriam corrompidos (ex: "canção" viraria "canÃ§Ã£o").
<meta charset="UTF-8">
meta name="viewport" Presente nas 3 páginas
Controla como a página é exibida em dispositivos móveis. O valor width=device-width, initial-scale=1.0 permite que usuários com baixa visão façam zoom na página sem que o layout quebre. Sem essa tag, a página seria renderizada em escala reduzida e ilegível.
<meta name="viewport" content="width=device-width, initial-scale=1.0">

3. HTML Semântico

Elementos semânticos descrevem o significado do conteúdo, não apenas sua aparência. Leitores de tela usam esses elementos para criar um mapa da página e permitir que o usuário navegue diretamente para seções específicas.

<nav> marketplace + cadastro + detalhes
Delimita regiões de navegação. O leitor de tela anuncia "navegação" ao entrar nesse elemento, e o usuário pode pular diretamente para ele ou pulá-lo. Usado na barra superior de todas as páginas e na paginação do marketplace.
<nav class="navbar navbar-main"> ... </nav>
<section> index.html
Agrupa conteúdo relacionado com significado próprio (o hero banner). Permite que tecnologias assistivas identifiquem regiões distintas da página.
<section class="hero-section"> ... </section>
<footer> index.html
Identifica semanticamente o rodapé da página. O leitor de tela permite que o usuário navegue diretamente para ele. Contém informações de contato, links úteis e direitos autorais.
<footer class="footer"> ... </footer>
<h1>, <h2>, <h4>, <h5>, <h6> todas as páginas
A hierarquia de títulos é fundamental para navegação por leitores de tela. Usuários podem listar todos os títulos da página e pular para qualquer seção diretamente, sem precisar ouvir todo o conteúdo.
<h1 class="hero-title">Encontre o carro ideal...</h1> <h2 class="detail-car-title">Chevrolet Onix</h2> <h6 class="detail-section-title">Itens do Veículo</h6>
<ol> Breadcrumb cadastro-veiculo.html
A trilha de navegação usa <ol> (lista ordenada), que é semânticamente correto pois a hierarquia de páginas tem uma ordem definida. O leitor de tela anuncia "lista ordenada com 2 itens", ajudando o usuário a entender onde está na estrutura do site.
<nav><ol class="breadcrumb"> <li class="breadcrumb-item"><a href="index.html">Veículos</a></li> <li class="breadcrumb-item active">Cadastrar</li> </ol></nav>

4. Texto Alternativo em Imagens alt

alt="descrição" marketplace + detalhes
O atributo alt fornece uma descrição textual de cada imagem. Para deficientes visuais, o leitor de tela lê esse texto no lugar da imagem. Também é exibido quando a imagem não carrega (conexão lenta, erro de URL). Todas as imagens de carros possuem alt descritivo com marca e modelo.
<!-- Imagem com alt descritivo --> <img src="foto-onix.jpg" alt="Chevrolet Onix"> <!-- Imagem decorativa (hero) --> <img src="foto-carro.jpg" alt="Carro">

5. Formulários Acessíveis

<label> cadastro-veiculo.html
Cada campo do formulário de cadastro tem um <label> associado. Quando o usuário foca em um campo (por teclado ou leitor de tela), o texto do label é anunciado automaticamente — ex: "Marca, obrigatório, caixa de seleção". Isso é essencial para usuários cegos que não podem ver o texto ao redor do campo.
<label class="form-label"> Marca <span class="req">(obrigatório)</span> </label> <select class="form-select">...</select>
type="text|tel|email" detalhes + cadastro
O atributo type correto em cada input tem dois benefícios de acessibilidade:
• type="tel": abre teclado numérico em celulares, facilitando para pessoas com dificuldade motora fina
• type="email": abre teclado com "@" e ativa validação nativa do browser antes de submeter
• Leitores de tela anunciam o tipo do campo ao focar: "campo de e-mail", "campo de telefone"
<input type="text" placeholder="Nome"> <input type="tel" placeholder="Telefone"> <input type="email" placeholder="Email">
placeholder todas as páginas
Exibe um texto de exemplo dentro do campo antes do usuário digitar. Ajuda especialmente usuários com dificuldades cognitivas a entender o formato esperado da informação — ex: "Ex.: 48.000" para quilometragem. Importante: placeholder não substitui label, pois desaparece ao digitar.
<input type="text" placeholder="Ex.: 48.000"> <input type="text" placeholder="Ex.: ABC1234 ou Final 3">
form-check-input em checkboxes marketplace + cadastro
A classe Bootstrap form-check-input estiliza os checkboxes aumentando a área visível de foco (outline azul ao navegar por teclado) e melhorando o contraste. Todos os checkboxes de filtros (Usados/Novos, marcas) e destaques do veículo utilizam essa classe.
<input type="checkbox" class="form-check-input"> <label class="form-check-label">Usados</label>
<select class="form-select"> todas as páginas
O elemento <select> nativo é totalmente acessível por teclado e leitores de tela. A classe Bootstrap form-select mantém o foco visível e o estilo consistente. Usado em filtros, ordenação e todos os campos do formulário de cadastro.
<select class="form-select"> <option>Selecione o câmbio</option> <option>Automático</option> </select>

7. CSS e Acessibilidade (style.css)

:root com variáveis de cor style.css
As variáveis CSS centralizadas (--nfs-dark, --nfs-blue, --nfs-accent) garantem consistência de cores em todo o projeto, facilitando futuras adequações de contraste para atender ao WCAG.
:root { --nfs-dark: #0c1a2b; --nfs-blue: #1a6eb5; --nfs-accent: #00c4e0; }
transition nos cards style.css
A transição suave nos car-cards (transition: transform 0.2s) respeita a preferência do sistema operacional. Em versões futuras, adicionar @media (prefers-reduced-motion) removeria animações para usuários com sensibilidade a movimentos.
.car-card { transition: transform 0.2s, box-shadow 0.2s; }
cursor: pointer em elementos interativos style.css
A área de upload de fotos (.photo-drop) usa cursor: pointer, sinalizando visualmente que o elemento é clicável — útil para usuários com dificuldades cognitivas que não identificam a interatividade apenas pelo visual.
.photo-drop { cursor: pointer; }
font-size em unidades relativas (rem) style.css
Quase todos os tamanhos de fonte usam rem em vez de px fixo. Isso permite que usuários que configuram o tamanho de fonte base do navegador (acessibilidade do sistema) tenham o layout escalando proporcionalmente.
.car-name { font-size: 0.93rem; } .hero-title { font-size: 2.1rem; }
